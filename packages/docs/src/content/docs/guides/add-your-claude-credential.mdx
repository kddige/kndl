Save your Claude credential on the Hub once, so every Session you start runs on your own Claude account, on any Runner.

Without one, your Sessions run on their Runner's own credential, if it has one. If no online Runner has one, **New Session** asks you to add yours.

## What you need

One of these:

- **A Claude subscription** (Pro, Max, Team or Enterprise), and Claude Code on any machine.
- **An Anthropic API key** (`sk-ant-api…`) from the Claude Console, billed per token.

The Hub also needs its secrets key, `HUB_SECRETS_KEY`, which whoever runs it sets up: see [Use variables and secrets](/guides/use-variables-and-secrets/#what-you-need).

## Add it

<Steps>

1. For a subscription, make a token on any machine with Claude Code:

   ```sh
   claude setup-token
   ```

   Sign in in the browser it opens. It prints a token starting `sk-ant-oat`, valid for a year. Copy all of it.

2. In kndl, press your name at the bottom of the sidebar, then **Account**.

   ![The Account page: the Claude section with a Token or API key field and Save, and the CLI tokens list.](../../../assets/screenshots/account.png)

3. Under **Claude**, paste the token or API key into **Token or API key**.

4. For a token, pick your **Plan**.

5. Press **Save**.

</Steps>

The Hub checks the credential with Anthropic before it stores it, at no cost. Once saved, the page shows its kind, its last 4 characters and its plan, never the credential itself.

If Anthropic rejects it, nothing is stored, and the Hub says why. Make a new token and try again: see [A Claude credential can't be saved](/troubleshooting/sessions/#a-claude-credential-cant-be-saved).

## Replace or remove it

- Press **Replace** to paste a new token, such as when the old one expires or your plan changes.
- Press **Remove** to take it off the Hub. Your Sessions then run on their Runner's credential.

A Session picks up the change the next time it starts or wakes.

## See whose account a Session uses

A Session's header names the account it runs on, such as **on Alice's Claude account**, or **on the Runner's Claude account**. Its subagents use the same account.
