kndl (said "kindle") runs coding-agent Sessions on machines you own, on the Models of any Provider you connect. Your team works in a Session together, live from the browser, on the accounts of whoever started it.

![A Session in kndl's web UI. The agent is mid-Turn: a subagent searches the docs in the background, tool calls are listed with their results, and Bob's prompt waits in the Prompt queue with a Steer button.](../../../assets/screenshots/session-live.png)

## What you get

- **Shared Sessions.** Everyone with access to a Repo can open its Sessions, follow the agent live and prompt it. Prompts sent while it works wait in a [Prompt queue](/reference/glossary/#prompt-queue), or join the running Turn with **Steer**. A [Thread](/guides/reply-in-a-thread/) forks the conversation at any answer and runs beside it.
- **A Sandbox per Session.** The agent and every command it runs live in a microVM on a Runner, never on the host.
- **Your machines.** The Hub and the Runners are yours: a laptop, a Mac mini under a desk, a Linux server. Nothing runs on a kndl service, because there isn't one.
- **Your own accounts, any Provider.** Each person connects their own [Providers](/guides/connect-your-providers/): a ChatGPT or GitHub Copilot sign-in, an API key, or a Claude setup token. The Sessions they start run on them, on any Runner, and switch Model mid-conversation. Everyone in a Session spends its Creator's accounts.

## How it fits together

<HowItWorks />

- **The Hub** is one Bun process with a SQLite database. It serves the web UI, signs people in with GitHub, and keeps every Session.
- **A Runner** is a machine that runs Sessions: a Mac with Apple Silicon, or Linux with KVM. It connects to the Hub, so the Hub needs no access to it.
- **A Sandbox** is the microVM a Session runs in, built from its Repo's [Environment](/concepts/environments/): an image and a setup script.

One machine can be the Hub and a Runner at once. That's how the [Quickstart](/start/quickstart/) runs it.

## Who it's for

- **You, trying it.** Install it on one machine, start a Session on one of your Repos, and remove it with one command if it isn't for you.
- **A team.** Run the Hub on a server, add a Runner or two, and invite the people who work on your Repos.

## What it isn't

- **Not a hosted service.** You run every part. There's no account to make and nothing to pay kndl for.
- **Not a fork of an agent.** The agent is built on [Pi Durable](https://earendil.com/posts/pi-durable/), as its makers publish it, and Claude's Models run through Claude Code as Anthropic publishes it, on your own accounts.
- **Not affiliated with Anthropic.** kndl is an independent open-source project. Claude and Claude Code are trademarks of Anthropic, PBC.
- **Not finished.** kndl is early. Expect settings to change between [Releases](/self-hosting/install/#update).
