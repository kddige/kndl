# kndl brand drafts (#196)

Drafts for the new name and logo, not final assets. The decisions are in #196.

- `kip.svg`: Kip on the night tile, for the app icon, favicon and GitHub App avatar.
- `kip-bare.svg`: Kip without the tile, for the web header, docs and README.
- `kip-mallow.svg`: Kip & Mallow, for the OG image, empty states and onboarding.
- `kip-working.svg`, `kip-waiting.svg`, `kip-done.svg`, `kip-asleep.svg`: Kip's moods (the follow-up issue).
- `concept-*.svg`: the concepts that weren't picked.
- `pages/`: the concept pages from the review (round 1, round 2, final). Open them in a browser.

Palette: night `#1D1733`, flame `#F6C445`, core `#FFEDB5`, logs `#8C5F47` and `#6B4A3A`, cheeks `#F59C8B`. Wordmark: Fraunces, soft, lowercase `kndl`.
